# Mapa vivo de Norte Luz

Prototipo del equipo e-Voltaria para el Reto i-DE · MDIT Deusto.

Versión web del prototipo: abre `index.html` o la página de GitHub Pages del repositorio.

Datos: población, subestaciones de i-DE y calles y transformadores de OpenStreetMap son reales; cargas de los centros de transformación y costes son simulados o de referencia.
